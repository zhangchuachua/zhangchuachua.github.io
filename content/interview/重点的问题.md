## 对 react fiber 的理解

在 react 16 之前，react 都是通过递归进行 diff, 更新的，因为是递归，所以中间的过程是不能中断的，一旦遇到大型项目，那么每次 re-render 都会出现卡顿的情况。所以在 react v17 后推出了 fiber 和 scheduler。

fiber 节点我理解中就是类似于 dom 对象，存储了元素的各种信息，而单一的 fiber 节点就是对 react 组件的抽象，fiber 对象中存储了组件的各种信息，比如 memoizedState 对函数组件来说就是 hooks 链表，memoizedProps 是上次渲染时的 props，child 是第一个子元素、return 是父元素等。

并且 fiber 可以组合成 fiber 树，就像 dom 树一样，表示了组件之间的结构。react 就是使用了双缓存树，一个用于渲染在浏览器中，一个用于在内存中进行更新，可以把多次更新合并成一次，优化了性能。

fiber 还可以与 scheduler 配合实现时间切片和优先级功能，每次遇到更新任务时，react 都会根据 fiber 树从上往下遍历处理，每次进入遍历之前就可以检查是否还有空闲时间，如果有空闲时间就交给浏览器进行渲染，这样就可以缓解卡顿的问题。

```ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { splitVendorChunkPlugin } from 'vite'

export default defineConfig({
  plugins: [vue(), splitVendorChunkPlugin()],
  
  build: {
    rollupOptions: {
      output: {
        // 自定义分包策略
        manualChunks(id) {
          // 1. 将大型库单独拆包
          if (id.includes('node_modules')) {
            if (id.includes('echarts')) return 'echarts'
            if (id.includes('lodash')) return 'lodash'
            if (id.includes('xlsx')) return 'xlsx'
            if (id.includes('d3')) return 'd3'
            
            // 2. 将React相关库单独分组（即使Vue项目有时也会混用）
            if (id.includes('react') || id.includes('react-dom')) {
              return 'react-vendor'
            }
            
            // 3. 核心框架单独分组
            if (id.includes('vue') || id.includes('vue-router') || id.includes('pinia')) {
              return 'vue-core'
            }
            
            // 4. 其他依赖合并为vendor
            return 'vendor'
          }
          
          // 5. 将大型工具文件单独拆包
          if (id.includes('src/utils/heavy-utils.js')) {
            return 'heavy-utils'
          }
          
          // 6. 按业务模块拆分（可选）
          if (id.includes('src/views/Dashboard')) {
            return 'dashboard-module'
          }
        },
        
        // 7. 文件命名规则
        chunkFileNames: 'js/[name]-[hash].js',
        entryFileNames: 'js/[name]-[hash].js',
        assetFileNames: 'assets/[name]-[hash][extname]'
      }
    },
    
    // 8. 分块大小警告阈值（150KB）
    chunkSizeWarningLimit: 150
  }
})
```
