## 首屏优化

先说明应用的问题：在没进行优化之前有哪些性能问题，在进行优化后使用指标来衡量有哪些提升。

指标：

1. FP first paint 首次绘制 发起请求到返回第一个字节的时间，与网络和后端处理有关
2. FCP first contentful paint 首次内容绘制 也就是白屏时间
3. FMP first meaningful paint 首次有效绘制 主要内容呈现时间
4. LCP largest contentful paint 最大内容绘制的时间

方案：

1. 优化图片：
	1. 格式：webp avif
	2. 图片压缩
	3. 图片尺寸（一倍图二倍图 sizes）
2. 字体瘦身 fontmin
3. 懒加载资源：图片懒加载，js 异步加载
4. css、js 打包优化，都需要进行下面的操作
	1. 代码压缩
	2. 文件合并
	3. 文件拆分
	4. tree shaking（消除死代码）
	5. 动态加载 import
5. 网络方面：[[CDN 如何决策资源请求？|使用 CDN]], [[如何在 nginx 中开启 gzip|使用 gzip]], [[HTTP-1, 1.1, 2, 3 有什么比区别|使用 http2]]
6. ssr、ssg

## 缓存优化

service worker?

```js
const registerServiceWorker = async () => {
  if ("serviceWorker" in navigator) {
    try {
      const registration = await navigator.serviceWorker.register("/sw.js", {
        scope: "/",// 作用域
      });
      if (registration.installing) {
        console.log("Service worker installing");
      } else if (registration.waiting) {
        console.log("Service worker installed");
      } else if (registration.active) {
        console.log("Service worker active");
      }
    } catch (error) {
      console.error(`Registration failed with ${error}`);
    }
  }
};
```

## 长任务优化

1. 使用 webworker
2. 将长任务分解为子任务，并且放到 setTimeout 中执行，运用 event-loop 与渲染线程交替执行
3. 使用 requestIdleCallback 把长任务等待空闲时再执行。也需要将长任务进行分解
