## 使用 raf 计算帧数

```js
let lastExecTime;
let fpsCount;
let fpsArray = [];
function calcFps() {
	const now = performance.now();
	if (fpsArray.length === 10) return;
	if (!lastExecTime) {
		lastExecTime = now;
		fpsCount = 1;
		window.requestAnimationFrame(calcFps);
		return;
	}

	if (now - lastExecTime < 1000) {
		fpsCount += 1;
		window.requestAnimationFrame(calcFps);
		return;
	}

	if (now - lastExecTime > 1000) {
		fpsArray.push(fpsCount)
	} else fpsArray.push(fpsCount + 1);

	lastExecTime = now;
	fpsCount = 0;
	window.requestAnimationFrame(calcFps);
}
calcFps();
```

## 还可以使用 longTask 检查长任务

假设显示器支持 120 fps，可能一个长任务使用了 61 fps 的时间，其他的任务没有占用时间，那么最后一秒的 fps 还是 60，所以仅仅计算 fps 不太完全。

```js
const observer = new PerformanceObserver((list) => {
	for (entry of list.getEntries()) {
		if (entry.duration > 50) {
			console.log('entry: ', entry);
		}
	}
})

observer.observe({ entryType: ['longtask'] })
```

## fid (first-input-delay) 首次输入延迟

依然使用 PerformanceObserver 去监听 first-input

```js
let startTime;
const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    if (entry.entryType === 'first-input') { 
    // 计算 FID
    const fid = entry.processingStart - entry.startTime; 
    console.log('FID:', fid); 
    // 可以在这里将 FID 发送到服务器或进行其他处理 }
  }
});
observer.observe({ entryTypes: ["first-input"] });
```
